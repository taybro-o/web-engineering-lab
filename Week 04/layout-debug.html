Bug 1: Flex Items Overflowing Row (Missing flex-wrap)

When multiple tags are placed inside a flex row without flex-wrap, items refuse to wrap and breach parent boundaries.

/* ============================================================= */
/* BUG 1: BROKEN vs FIXED CSS ANNOTATION */
/* ============================================================= */
/* BROKEN: No flex-wrap causes elements to overflow bounding box */
.tag-container-broken {
  display: flex; /* missing flex-wrap: wrap; */
  gap: 8px;
}

/* FIXED: Adding flex-wrap: wrap preserves container integrity */
.tag-container-fixed {
  display: flex;
  flex-wrap: wrap; /* <-- FIX APPLIED */
  gap: 8px;
}

Bug 2: Absolute Notification Badge Escaping Parent Card

When an element has position: absolute but its parent container lacks position: relative, the badge escapes the container and attaches to the top-level viewport window.

/* ============================================================= */
/* BUG 2: BROKEN vs FIXED CSS ANNOTATION */
/* ============================================================= */
/* BROKEN: Parent lacks positioning context; badge attaches to body */
.card-parent-broken {
  width: 240px;
  /* missing position: relative; */
}

/* FIXED: Adding position: relative creates the containing block */
.card-parent-fixed {
  width: 240px;
  position: relative; /* <-- FIX APPLIED */
}

Task 2 Predictions and Explanations

1. 0 == false
Prediction: true
Output: true
Reason: Loose equality coerces false to 0, so 0 == 0.

2. 0 === false
Prediction: false
Output: false
Reason: Strict equality checks type without coercion (number !== boolean).

3. [] == false
Prediction: true
Output: true
Reason: [] converts to "" which coerces to 0, so 0 == 0.

4. [] == ![]
Prediction: true
Output: true
Reason: ![] is false because arrays are truthy. Then [] == false becomes true.

5. null == undefined
Prediction: true
Output: true
Reason: In JavaScript null and undefined are loosely equal by specification.

6. null === undefined
Prediction: false
Output: false
Reason: Different types (null vs undefined).

7. typeof NaN
Prediction: number
Output: number
Reason: In JS, NaN is still classified as a numeric type.

8. 0 || 42 vs 0 ?? 42
Prediction: 42 vs 0
Output: 42 vs 0
Reason: || treats 0 as falsy, but ?? only checks for null or undefined.

9. [10, 2, 5, 1].sort()
Prediction: [1, 10, 2, 5]
Output: [1, 10, 2, 5]
Reason: Default sort converts elements to strings and sorts alphabetically ("10" comes before "2").
